# CybernetLab

Sito responsive in HTML, CSS e JavaScript, realizzato dal mockup fornito. Nessuna dipendenza da installare.

## Aprire in Visual Studio Code

Apri `cybernetlab.code-workspace` in Visual Studio Code, oppure scegli File → Apri cartella e seleziona questa cartella.

Con Node.js installato, apri il terminale integrato ed esegui `npm run dev`. Visita http://127.0.0.1:5173. In alternativa apri `index.html` direttamente nel browser oppure usa l'estensione Live Server.

## Modifiche

- `index.html`: contenuti e sezioni.
- `style.css`: colori, impaginazione e versione mobile.
- `script.js`: servizi, fasi di lavoro, schede progetto e interazioni.
- `assets/`: immagini e favicon.

Il pulsante Contattaci apre il programma email verso **infocybernet24@gmail.com**. Non è presente un backend per l'invio di messaggi. I progetti aprono schede informative interne: i relativi URL pubblici non sono stati forniti.

Le anteprime dei tre progetti usano porzioni del mockup originale tramite CSS; per maggiore definizione sostituirle con screenshot originali dei prodotti. Lo sfondo principale è una nuova illustrazione generata, ispirata al riferimento: non è una copia pixel per pixel. Il font Inter viene richiesto a Google Fonts, con Arial come alternativa offline.

Prima della pubblicazione integrare i dati societari e gli eventuali documenti privacy applicabili. Il sito è preparato localmente e non è stato pubblicato.
